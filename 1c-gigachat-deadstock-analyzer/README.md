# Отчёт по непродаваемым товарам в 1С:УТ 11.5 с ИИ-аналитикой

## Описание проекта

Отчёт на СКД для анализа неликвидов и избыточных запасов в 1С:УТ 11.5.

Показывает проблемные позиции: остатки, суммы, даты последних закупок и продаж, срок без продаж, сумму залежалого товара. Сортирует по сумме замороженных средств.

Дополнительно — кнопка «Анализ AI», которая формирует текстовый разбор на основе данных отчёта: объясняет, почему позиция проблемная, и предлагает конкретные действия.

## Бизнес-задача

Менеджеры и руководители отдела закупок тратили часы на ручной анализ отчётов по складу:

- «Что у нас залежалось?»
- «Где заморожены деньги?»
- «Что с этим делать?»

Стандартный отчёт показывал цифры, но не давал ответов. Читать таблицу на 200 строк и вручную искать проблемные позиции — долго и неэффективно.

## Решение

**Основное — отчёт на СКД.** Он собирает данные из регистров, считает вычисляемые поля, сортирует по сумме замороженных средств и выводит проблемные позиции.

**Дополнительное — ИИ-надстройка.** По кнопке «Анализ AI» код 1С:

1. Определяет ТОП-5 неликвидов и ТОП-5 избытков.
2. Выбирает готовую рекомендацию по сроку простоя.
3. Формирует разбивку по категориям.
4. Отправляет данные в GigaChat и получает текстовый разбор.

Ключевой принцип: **SQL считает, код решает, ИИ объясняет**.

## Возможности отчёта

- Параметры:
  - период,
  - вид цены,
  - дата последней продажи (граница).
- Вычисляемые поля:
  - остаток,
  - цена,
  - сумма,
  - дата последней закупки,
  - дата последней продажи,
  - дней без продаж,
  - сумма залежалого товара.
- Группировка по номенклатуре, характеристике, складу.
- Сортировка по сумме замороженных средств.
- Фильтр: только позиции с остатком > 0.

## Возможности ИИ-надстройки

- Разделение на неликвиды (от 180 дней) и избытки (от 90 дней).
- Определение ТОП-5 по каждому классу.
- Сортировка по сумме замороженных средств, а не по количеству.
- Определение рекомендации по сроку простоя:
  - менее 500 дней — уценка 10-20% и акция,
  - от 500 до 1500 — распродажа со скидкой 30-50%,
  - более 1500 — списание или уценка до себестоимости.
- Определение рекомендации по избытку на основе остатка.
- Разбивка по категориям с количеством позиций и суммой.
- Отправка промпта в GigaChat.
- Вывод текстового анализа в поле отчёта.
- Кнопки «Показать анализ» и «Скрыть анализ».

## Ключевые технические решения

### По отчёту

**1. Вычисляемые поля в СКД.**

Поля «Дней без продаж» и «Сумма залежалого товара» вычисляются в запросе, а не в коде после СКД. Это позволяет сортировать и фильтровать по ним.

**2. Соединение с регистрами закупок и продаж.**

Одним запросом получаются последняя закупка, последняя продажа и последняя цена. Это избавляет от тысяч отдельных обращений к базе.

**3. Сортировка по сумме замороженных средств.**

Стандартный отчёт сортирует по количеству или по дням. Это не отражает реальную картину: 2 дорогие позиции могут держать больше денег, чем 500 дешёвых. Сортировка по сумме показывает, где реально заморожены деньги.

### По ИИ-надстройке

**4. Разделение ответственности: SQL считает, код решает, ИИ объясняет.**

LLM не умеет надёжно сравнивать числа, ранжировать и агрегировать. В проекте:

- SQL считает остатки, суммы, сроки, категории.
- Код 1С ранжирует, выбирает ТОП-5, определяет рекомендацию по сроку.
- GigaChat получает готовые данные и готовые решения — и оформляет их в текст.

**5. Рекомендации определяются в коде, а не в промпте.**

Функции `ОпределитьРекомендациюПоСроку` и `ОпределитьРекомендациюПоИзбытку` возвращают готовое решение на основе чисел. GigaChat не выбирает решение — он его дословно вставляет в ответ.

**6. Разделение неликвидов и избытков.**

Неликвид — товар, который давно не продаётся. Избыток — товар, которого много, но он ещё продаётся. Это разные классы, и решения по ним разные.

**7. Ограничения для GigaChat.**

Промпт содержит 20 жёстких правил, которые запрещают выдумывать товары, менять числа, использовать запрещённые глаголы, упоминать несуществующие сущности.

## Пример ответа GigaChat
Дата анализа: 11.10.2026

Неликвиды — разбор:

    К-9881 Кондиционер ELEKTA, заморожено: 28872 руб., дней без продаж: 3390.
    Что делать: списание или уценка до себестоимости.

    Кофе-машина "Универсал", заморожено: 22355 руб., дней без продаж: 1347.
    Что делать: распродажа со скидкой 30-50%.
    ...

Общий вывод:
Наибольший объём замороженных средств наблюдается в категории электротоваров.

Три действия на неделю:

    Подготовка акта списания на кондиционер ELEKTA (К-9881).

    Согласование скидки 30-50% на кофе-машину «Универсал».

    Создание рекламной акции на комбайн кухонный BINATONE FP 67.

- Построение отчёта на СКД с параметрами и вычисляемыми полями.
