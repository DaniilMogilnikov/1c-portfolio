# Интеграция 1С с мессенджером VK на базе HTTP-сервисов

## Описание проекта

B2B-портал самообслуживания клиентов для компании «Веломастерская».

Клиенты могут самостоятельно проверять статусы заказов и историю своих заказов через мессенджер VK, без участия менеджеров.

## Бизнес-задача

Менеджеры тратили до 40% рабочего времени на ответы на типовые вопросы клиентов:
- «Где мой заказ?»
- «Какой статус у заказа?»
- «Какие заказы у меня были?»

## Решение

Разработан бот в VK, который через REST API обращается к 1С и получает актуальные данные.

## Архитектура
Клиент (VK)
↓ сообщение
Python-бот (Long Poll API)
↓ HTTP GET
IIS (веб-сервер)
↓
1С HTTP-сервис (api)
↓ запрос
База данных 1С
↓ JSON-ответ
Python-бот
↓ ответ
Клиент (VK)
## Стек технологий

1С:Предприятие 8.3 Бизнес-логика, работа с данными
HTTP-сервисы 1С REST API 
IIS  Веб-сервер, публикация базы
Python 3 Бот, интеграция с VK 
VK Bot API  Мессенджер 
JSON  Формат обмена данными 

## Возможности бота

- Проверка статуса заказа по номеру
- Список заказов клиента по номеру телефона
- Кнопки меню
- Многошаговые диалоги (бот запоминает, что ждет от пользователя)
- Обработка ошибок (заказ не найден, 404)

## HTTP-сервис 1С

### Методы

GET  `/status/{номер}`  Статус заказа по номеру 
GET `/orders/{телефон}`  Список заказов по телефону

### Пример запроса

GET http://localhost/InfoBase/hs/api/status/000000001

### Пример ответа

{"статус": "В работе"}
