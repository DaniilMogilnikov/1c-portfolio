# Портфолио 1С-разработчика

Коммерческая разработка на 1С:Предприятие 8.3, УТ 11.5.
Интеграции с внешними API, отчёты на СКД, обработки загрузки данных, HTTP-сервисы, ИИ-аналитика.

---

## О себе

1С-разработчик с коммерческим опытом доработки и поддержки конфигураций на базе 1С:УТ 11.5.

Специализируюсь на автоматизации бизнес-процессов, интеграциях с внешними сервисами (REST API, HTTP-сервисы) и внедрении элементов ИИ для аналитики. Умею переводить требования бизнеса на технический язык, писать чистый код и документировать решения. Готов к сложным задачам и быстрому обучению новым подсистемам.

**Опыт работы:** 1С-разработчик, КА ЛиКом (сентябрь 2024 — ноябрь 2025).

**Ищу:** позицию 1С-разработчика с интересными интеграционными и аналитическими задачами.

**Стек:** 1С:Предприятие 8.3, УТ 11.5, СКД, HTTP-сервисы, REST API, OAuth 2.0, JSON, Python, IIS, Git, GigaChat API.

---

## Ключевые достижения и проекты

### 1. Система умной аналитики складских запасов

- Разработал сложный отчёт на СКД для выявления неликвидных товаров с динамическими параметрами фильтрации.
- Интегрировал отчёт с нейросетью GigaChat: система автоматически генерирует текстовые рекомендации по распродаже залежалого товара.
- Оптимизировал производительность: время формирования сократилось **с 2 минут до 15 секунд** за счёт правильной настройки индексации и временных таблиц.
- **Результат:** отдел закупок получил инструмент для еженедельного выявления товаров с замороженными средствами без ручного анализа Excel.

### 2. Автоматизация ведения справочника Номенклатуры

- Реализовал механизм массовой загрузки и обновления карточек товаров из прайс-листов поставщиков (Excel/XLSX).
- Внедрил алгоритм интеллектуального сопоставления колонок и защиту от дубликатов через поиск по аналогам.
- Разработал функцию автогенерации SEO-описаний товаров через API GigaChat с предпросмотром и редактированием менеджером.
- **Результат:** скорость заведения новой номенклатуры выросла **в 5 раз**, количество ошибок в описаниях снизилось до минимума.

### 3. Интеграция 1С с мессенджерами (Proof of Concept)

- **Цель:** изучение механизмов взаимодействия 1С с внешними системами через HTTP-сервисы и REST API.
- Разработал архитектуру обмена данными между 1С и Python-ботом ВКонтакте (Long Poll API).
- Настроил публикацию базы на веб-сервере IIS, обеспечил безопасность соединений.
- Реализовал многошаговые диалоги для проверки статусов заказов пользователями.
- **Результат:** освоил полный цикл создания HTTP-сервисов в 1С, обработку JSON, OAuth 2.0 и отладку межсистемного взаимодействия.

### 4. Поддержка и оптимизация текущей базы

- Регулярно проводил обновления платформы и конфигурации.
- Настроил ролевую модель доступа для новых сотрудников отдела продаж.
- Доработал печатные формы счетов и накладных под требования бухгалтерии.
