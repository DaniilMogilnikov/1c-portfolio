# Портфолио 1С-разработчика

Практические проекты на 1С:Предприятие 8.3, УТ 11.5.

Интеграции с внешними API, отчёты на СКД, обработки загрузки данных, HTTP-сервисы, работа с ИИ.

---

## О себе

Начинающий 1С-разработчик. 5 месяцев практики. Реализовал 4 учебных проекта, приближенных к реальным бизнес-задачам.

**Ищу:** junior-позицию 1С-разработчика, стажировку у франчайзи, работу в команде интеграторов.

**Стек:** 1С:Предприятие 8.3, УТ 11.5, СКД, HTTP-сервисы, REST API, OAuth 2.0, JSON, Python, IIS, GigaChat API.

---

## Проекты

| Проект | Задача | Стек |
|---|---|---|
| [01. Отчёт по неликвидам с ИИ-аналитикой](deadstock-report-gigachat/) | Отчёт на СКД для анализа неликвидов и избытков. Дополнительно — кнопка «Анализ AI», которая через GigaChat формирует текстовый разбор с рекомендациями. | 1С:УТ 11.5, СКД, HTTP, GigaChat API, OAuth 2.0 |
| [02. AI-генерация описаний номенклатуры](gigachat-nomenclature/) | Внешняя обработка для автоматического заполнения продающих описаний товаров через GigaChat. | 1С:УТ 11.5, HTTP, REST API, OAuth 2.0, JSON |
| [03. VK-бот для отслеживания заказов](vk-bot-orders/) | B2B-бот: клиенты проверяют статусы заказов через VK. Python-бот + HTTP-сервис на стороне 1С. | 1С:УТ 11.5, HTTP-сервисы, Python, VK Bot API, IIS |
| [04. Загрузка номенклатуры из Excel](excel-nomenclature-loader/) | Внешняя обработка для импорта из XLSX/XLS/ODS/MXL. Автосопоставление колонок, поиск дубликатов, создание новых позиций. | 1С:УТ 11.5, ТаблицаЗначений, менеджер временных таблиц |

## Навыки

**Платформа 1С:**

- 1С:Предприятие 8.3, конфигурация УТ 11.5
- Встроенный язык 1С
- СКД: отчёты с параметрами, вычисляемые поля, группировки
- Управляемые формы: клиент-серверное взаимодействие
- Справочники, документы, регистры накопления и сведений
- Таблицы значений, структуры, соответствия
- Менеджер временных таблиц, временные таблицы в запросах
- Внешние обработки и отчёты (`.epf`, `.erf`)

**Интеграции:**

- HTTP-соединение, HTTP-сервисы 1С
- REST API, OAuth 2.0
- JSON: чтение и запись
- HTTPS, защищённое соединение OpenSSL
- Публикация базы через IIS

**Дополнительно:**

- Python 3: requests, Long Poll API
- VK Bot API
- GigaChat API
- Формулирование промптов для LLM
