#  Портфолио 1С-разработчика

Добро пожаловать! Здесь представлены проекты, демонстрирующие компетенции в разработке на платформе **1С:Предприятие** с интеграцией современных технологий.

Основной фокус — создание надежных, документированных решений для автоматизации бизнес-процессов: от AI-интеграций до B2B-взаимодействия. Каждый проект оформлен как самостоятельный продукт с полной технической документацией, инструкциями по развертыванию и примерами использования.

## 🛠 Технический стек и компетенции

### Платформа 1С:Предприятие
*   **Серверная разработка:** HTTP-сервисы (REST API), общие модули, регламентные задания.
*   **Работа с данными:** Сложные запросы (ЛЕВОЕ СОЕДИНЕНИЕ, ПОДОБНО, пакетная обработка), регистры сведений, блокировки данных для обеспечения целостности.
*   **Интерфейсы:** Внешние обработки, управляемые формы, работа с табличными документами.

### Интеграции и современные технологии
*   **API & Web:** Работа с внешними сервисами (GigaChat, VK), авторизация OAuth 2.0, обработка JSON/XML.
*   **Обработка ошибок:** Реализация механизмов retry для лимитов API (429), обработка исключений (401, 500).
*   **Смежные технологии:** Python (для ботов), работа с файловой системой (XLSX, ODS).
