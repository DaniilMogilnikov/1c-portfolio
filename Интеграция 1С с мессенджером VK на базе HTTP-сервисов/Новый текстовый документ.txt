Полное объяснение проекта
1. Что это за проект

Это интеграция 1С с мессенджером VK для автоматизации ответов клиентам.

Проблема: менеджеры тратят время на ответы «Где мой заказ?»

Решение: бот сам отвечает на эти вопросы, беря данные из 1С.
2. Из чего состоит

Три части:

    1С — база данных с заказами

    Python-бот — посредник между VK и 1С

    IIS — веб-сервер, который публикует 1С

3. Как они связаны
text

Пользователь → VK → Python-бот → IIS → 1С → База данных
                                    ↓
Пользователь ← VK ← Python-бот ← JSON-ответ

4. Что происходит при запросе

Пользователь пишет в VK:

    /status 000000001

Python-бот:

    Через Long Poll получает сообщение

    Понимает, что это команда /status

    Извлекает номер заказа: 000000001

    Делает HTTP-запрос: GET http://localhost/InfoBase/hs/api/status/000000001

IIS:

    Принимает запрос

    Передает его в 1С

1С (HTTP-сервис):

    Находит шаблон /status/{номер}

    Вызывает функцию-обработчик

    Функция выполняет запрос к базе

    Находит документ «Заказ клиента» с нужным номером

    Формирует JSON: {"статус": "В работе"}

    Возвращает ответ

Python-бот:

    Получает JSON

    Формирует красивое сообщение

    Отправляет пользователю в VK

5. Два метода API
Метод	Что делает
/status/{номер}	Возвращает статус заказа
/orders/{телефон}	Возвращает список заказов клиента
6. Кнопки и диалог

Бот не просто отвечает на команды — он ведет диалог:

    Пользователь жмет кнопку «📦 Узнать статус заказа»

    Бот запоминает: «Этот пользователь сейчас должен ввести номер»

    Просит: «Введите номер заказа»

    Пользователь вводит номер

    Бот понимает: «Ага, это номер заказа» — и обрабатывает
