# Интеграция 1С с мессенджером VK на базе HTTP-сервисов

## Описание проекта

Инструмент автоматизации для менеджеров по ассортименту в 1С:УТ 11.5.

Пользователь выбирает товар, задаёт промпт — и получает готовое продающее описание, сгенерированное нейросетью GigaChat от Сбера, прямо в карточке номенклатуры.

## Бизнес-задача

Менеджеры тратили часы на рутинное заполнение описаний для сотен позиций номенклатуры:

    «Надо написать текст для карточки товара»

    «Описание должно быть уникальным и продающим»

    «Одинаковые тексты плохо влияют на SEO и маркетплейсы»

Ручное заполнение — это медленно, дорого и приводит к однотипным текстам.

## Решение

Разработана внешняя обработка для 1С:УТ 11.5, которая через REST API обращается к GigaChat и записывает полученное описание прямо в справочник Номенклатура.

## Архитектура
Пользователь (1С)
↓ выбор товара + промпт
Форма обработки (клиент)
↓ вызов серверной функции
Модуль формы (сервер 1С)
↓ HTTPS POST
GigaChat API (Сбер)
↓ JSON-ответ
Модуль формы (разбор ответа)
↓ запись
Справочник.Номенклатура
## Стек технологий

1С:Предприятие 8.3 Бизнес-логика, работа с данными
1С:УТ 11.5 Конфигурация, справочник Номенклатура
HTTP-сервисы 1С Отправка и приём REST-запросов
GigaChat API Генерация текста нейросетью
OAuth 2.0 Авторизация в GigaChat
JSON Формат обмена данными
HTTPS Защищённый канал связи

## Возможности бота

Генерация описания по текстовому промпту пользователя

Настройка промпта прямо в форме — без правки кода

Пакетная обработка по видам номенклатуры (для каждого вида — свой промпт)

Предпросмотр результата перед записью

Ручное редактирование сгенерированного текста

Запись описания в справочник Номенклатура

Обработка ошибок API (401, 429, 500)

Регистрация как дополнительной обработки — вызов из карточки товара

## HTTP-сервис 1С

### Методы

POST /api/v2/oauth Получение Access Token
POST /api/v1/chat/completions Генерация текста
POST /api/v1/files Загрузка файлов
GET /api/v1/files/{id}/content Скачивание файла

### Пример запроса

POST https://gigachat.devices.sberbank.ru/api/v1/chat/completions
Authorization: Bearer <access_token>
Content-Type: application/json

{
"model": "GigaChat",
"messages": [
{
"role": "user",
"content": "Напиши краткое продающее описание для товара: Велосипед горный"
}
],
"temperature": 0.7
}

### Пример ответа

{"choices": [{"message": {"content": "Надёжный горный велосипед для активного отдыха. Прочная рама, амортизационная вилка, 21 скорость."}}]}
