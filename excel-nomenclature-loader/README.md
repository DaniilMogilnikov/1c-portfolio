# Загрузка номенклатуры в 1С:УТ 11.5 из Excel

Внешняя обработка для 1С:Предприятие 8.3 (УТ 11.5), которая загружает
номенклатуру из файлов Excel и OpenDocument в справочник «Номенклатура».

Обработка сама сопоставляет колонки файла с полями номенклатуры,
находит существующие позиции, создаёт новые, заполняет производителя,
марку и штрихкоды.

---

## Возможности

### Загрузка файла
- Поддержка форматов **XLSX, XLS, ODS, MXL** — нативное чтение платформой.
- Выбор файла через диалог, передача на сервер через временное хранилище.

### Сопоставление заголовков
- Автоматическое определение колонок по заголовкам с учётом синонимов
  (`Barcode`, `EAN`, `SKU`, `Бренд` и т.д.).
- Нормализация заголовков — регистр, пробелы, дефисы, скобки.
- 6 полей: Наименование, Артикул, Код, Штрихкод, Марка, Производитель.

### Поиск
- **Один запрос** на все строки файла через менеджер временных таблиц
  вместо тысяч отдельных запросов.
- Условие **ИЛИ** — находит запись по любому отмеченному полю.
- **Добор по ПОДОБНО** для тех строк, где точное совпадение не сработало.

### Создание номенклатуры
- Автоматическое заполнение Наименования и Артикула.
- Поиск или создание производителя и марки в соответствующих справочниках.
- Запись штрихкода в регистр сведений.

### Защита от ошибок
- **Валидация** перед запуском: обязательность Наименования, проверка
  номеров колонок, наличие данных в колонке Наименования.
- **Проверка дубликатов** внутри файла — одинаковые строки не создаются дважды.
- Обработка ошибок по каждой строке отдельно — сбой одной не роняет всю операцию.

### Результат
- Таблица результатов с указанием причины по каждой строке.
- Подсветка: зелёный — создано, оранжевый — дубликат, красный — ошибка.
- Итог: сколько найдено, создано, пропущено дубликатов, ошибок.

## Технологии

- 1С:Предприятие 8.3 (тонкий клиент)
- Конфигурация УТ 11.5
- Встроенный язык 1С
- Табличный документ, ТаблицаЗначений
- Менеджер временных таблиц, временные таблицы в запросах
- Справочники, регистры сведений


## Ключевые технические решения

### Оптимизация поиска через менеджер временных таблиц

1. Все строки файла собираются в `ТаблицаЗначений`.
2. Таблица помещается во временную таблицу через `ПОМЕСТИТЬ`.
3. Поиск выполняется **одним запросом** с `ЛЕВЫМ СОЕДИНЕНИЕМ`.

### Двухуровневый поиск

1. **Точное совпадение** по всем отмеченным полям одним запросом.
2. **Добор по ПОДОБНО** — для тех, где точный поиск не сработал.
   Шаблон строится так, чтобы игнорировать пробелы, дефисы и регистр:
   `"Гвоздь 100 мм"` → `%г%в%о%з%д%ь%1%0%0%м%м%`.

### Защита от дубликатов

Перед созданием проверяется:
- нет ли такой же строки выше в файле (ключ «Наименование + Артикул»);
- нет ли уже записи в справочнике (поиск + добор по ПОДОБНО).

### Валидация перед запуском

Проверяется до начала операции:
- файл загружен;
- отмечено хотя бы одно поле;
- среди отмеченных есть Наименование (обязательное);
- номера колонок не превышают ширину файла;
- в колонке Наименования есть данные.
