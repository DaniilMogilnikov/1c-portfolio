# Портфолио 1С-разработчика

Коммерческая разработка на платформе **1С:Предприятие 8.3** (УТ 11.5), проектирование интеграционных решений (REST API, HTTP-сервисы), разработка отчетности на СКД и автоматизация бизнес-процессов с использованием ИИ-сервисов.

---

## 🚀 О себе

1С-разработчик с опытом доработки, поддержки и развития конфигураций на базе **1С:УТ 11.5**. 

Специализируюсь на создании отказоустойчивых интеграций с внешними сервисами и мессенджерами (REST API, JSON, OAuth 2.0, Python) и внедрении элементов машинного обучения / LLM для бизнес-аналитики. Умею переводить требования заказчика на строгий технический язык, оптимизировать тяжелые запросы СУБД и документировать архитектуру решений.

---

## 🛠️ Технологический стек

* **Платформа 1С 8.3:** СКД (вычисляемые поля, динамическая фильтрация, детальная настройка оформления), Управляемые формы (клиент-серверное взаимодействие), оптимизация запросов (Менеджер временных таблиц, индексация), разработка внешних обработок и отчетов (`.epf`, `.erf`).
* **Интеграции и Протоколы:** HTTP-соединения, разработка собственных HTTP-сервисов на стороне 1С, REST API, OAuth 2.0, обмен данными в формате JSON, HTTPS (OpenSSL).
* **Инфраструктура и DevOps:** Публикация информационных баз на веб-сервере IIS, администрирование систем Windows/Сети, контроль версий Git.
* **Дополнительно:** Python 3 (requests, Long Poll API), VK Bot API, GigaChat API (промпт-инжиниринг с жесткими бизнес-ограничениями).

## 📂 Ключевые проекты в репозитории

### 1. [Система умной аналитики складских запасов](./1c-gigachat-deadstock-analyzer)
* **Стек:** 1С:Предприятие 8.3, СКД, HTTP-сервисы, GigaChat API, JSON, OAuth 2.0.
* **Задача:** Сократить время менеджеров отдела закупок на ручной анализ неликвидных товаров в Excel и формирование стратегий по их распродаже.
* **Решение:** Разработал сложный аналитический отчет на СКД с динамическими параметрами фильтрации. Интегрировал решение с LLM GigaChat для автоматической генерации текстовых бизнес-рекомендаций по списанию или уценке залежалого товара прямо в интерфейсе 1С.
* **Результат:** Время формирования отчета сокращено **с 2 минут до 15 секунд** за счет оптимизации временных таблиц и индексации. Отдел закупок получил автоматизированный инструмент еженедельного контроля замороженных средств.

### 2. [Автоматизация ведения справочника «Номенклатура»](./gigachat-nomenclature)
* **Стек:** 1С:Предприятие 8.3, HTTP-сервисы, REST API, JSON, GigaChat API.
* **Задача:** Ускорить рутинный процесс ручного заполнения уникальных SEO-описаний для сотен новых карточек товаров.
* **Решение:** Создал внешнюю обработку, которая через REST API обращается к модели GigaChat и генерирует продающий текст по свойствам номенклатуры. Реализовал механизм пакетной обработки по видам номенклатуры, предпросмотр и ручную модерацию перед записью в базу.
* **Результат:** Скорость заведения и наполнения карточек новой номенклатуры выросла **в 5 раз**, полностью исключены дубликаты и однотипные тексты.

### 3. [Инструмент бесшовного импорта данных из Excel](./excel-nomenclature-loader)
* **Стек:** 1С:Предприятие 8.3, Язык запросов 1С, Менеджер временных таблиц, ТаблицаЗначений.
* **Задача:** Автоматизировать загрузку разноформатных прайс-листов поставщиков, минимизировав человеческий фактор и появление дублей.
* **Решение:** Разработал обработку массовой загрузки (XLSX, XLS, ODS, MXL) с алгоритмом интеллектуального сопоставления колонок по синонимам и валидацией данных. Поиск существующих позиций реализован через двухуровневый алгоритм (точное совпадение + добор по `ПОДОБНО`).
* **Результат:** Поиск и проверка тысяч строк выполняются **одним запросом** к СУБД через временные таблицы вместо циклического обращения к базе. Скорость импорта увеличилась в 5–7 раз.

### 4. [B2B-прототип: Интеграция 1С с мессенджером VK](./vk-bot-orders)
* **Стек:** Python 3 (Long Poll API), 1С:Предприятие 8.3 (HTTP-сервисы), Веб-сервер IIS, REST, JSON.
* **Задача:** Снизить нагрузку на менеджеров компании (до 40% входящих звонков) по типовым вопросам клиентов о статусах заказов.
* **Решение:** Спроектировал и настроил архитектуру сквозного обмена «Клиент ↔ VK Bot ↔ IIS ↔ 1С». Разработал HTTP-сервис на стороне 1С для отдачи данных по GET-запросам, написал асинхронный клиент на Python с поддержкой многошаговых диалогов.
* **Результат:** Создан рабочий Proof of Concept автоматического вывода актуальных статусов и истории заказов напрямую из рабочей базы 1С в интерфейс мессенджера.
