# 💼 Портфолио 1С-разработчика

Привет! Я 1С-разработчик. Здесь собраны мои проекты, которые показывают
навыки на стыке 1С и современных технологий: интеграции с AI, автоматизация
загрузки данных и построение B2B-порталов самообслуживания.

Для меня это не просто «решённые задачи» — каждый проект я переосмыслил,
оптимизировал и оформил как самостоятельное решение с документацией,
скриншотами и инструкцией по запуску.

Это моё портфолио, где я показываю не только знание платформы,
но и умение документировать код, анализировать сложности
и находить обходные пути.

## 🔧 Используемые технологии 1С

- **HTTP-сервисы** — публикация REST API, приём GET/POST-запросов
- **Справочники** — номенклатура, контрагенты, производители, марки
- **Регистры сведений** — штрихкоды номенклатуры
- **Документы** — заказы клиентов
- **Общие модули** — вынос серверной логики и алгоритмов
- **Запросы** — временные таблицы, ЛЕВОЕ СОЕДИНЕНИЕ, ПОДОБНО, пакетные запросы
- **Табличный документ, ТаблицаЗначений** — работа с файлами и данными
- **Внешние обработки** — регистрация как дополнительных, вызов из карточки товара
- **OAuth 2.0** — авторизация в GigaChat
- **Блокировки данных** — управляемые блокировки для корректной параллельной работы

## 💼 Реализованные механизмы

- **AI-интеграция** — генерация текста через GigaChat API с настройкой промпта
  без правки кода, пакетная обработка по видам номенклатуры
- **Импорт данных** — чтение XLSX, XLS, ODS, MXL, нормализация заголовков,
  сопоставление по синонимам (`Barcode`, `EAN`, `SKU`, `Бренд` и т.д.)
- **Двухуровневый поиск** — точное совпадение + добор по ПОДОБНО
- **Защита от дубликатов** — внутри файла и в справочнике
- **Валидация перед запуском** — проверка обязательных полей и номеров колонок
- **B2B-самообслуживание** — многошаговые диалоги в VK, кнопочное меню
- **Обработка ошибок API** — 401, 429, 500, 404

## 🚀 Как открыть и протестировать

1. Создайте новую информационную базу 1С:УТ 11.5.
2. В конфигураторе выберите **«Конфигурация → Загрузить конфигурацию из файлов»**
   и укажите папку `tasks/*проект*/src/Configuration` (для загрузки в формате XML).
3. В конфигураторе выберите **«Администрирование → Загрузить информационную базу»**
   и укажите файл `tasks/*проект*/dist/*.dt` (для загрузки в формате .dt).
4. Запустите в режиме предприятия.

**Важно:** при выгрузке в формате XML документы и прочие объекты, созданные
в режиме предприятия, не выгружаются. Их необходимо создать самостоятельно
для проверки или загрузить информационную базу в формате .dt, где уже
созданы объекты для демонстрации.

**Для проекта с VK-ботом дополнительно:**
разверните Python-бота из папки `bot/` (инструкция в README проекта).
